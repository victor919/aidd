# 第13篇修订版：分子生成与评分反馈

当前公众号文章配套代码。固定同一片段提议函数、起点与候选逻辑评分预算，仅改变保留规则：随机保留 / RF贪心保留。

## 与已有gen_demo的关系

本目录与同仓库`aidd_practice/gen_demo/`是不同协议，互不覆盖，不拼接数字。

- 本目录：按骨架留出验证集，7148拟合；6起点×3种子×2臂=36条单状态轨迹，每条10轮×8候选请求。GNN为第12篇128隐藏维模型，仅事后评分。
- gen_demo：附件的三臂束搜索；拟合分子集合、保留规则、查询成本和GNN协议不同。即使训练样本数一样，也不是同一训练集合。

## 结果与边界

RF终点均值：随机5.541，贪心7.905；最近邻相似性均值：随机0.314，贪心0.703。本次没有出现“贪心臂比随机臂更远”的均值趋势。贪心4/18条轨迹终点回到拟合池，RF最高分终点也是已知结构，不当成新分子发现。

每臂18条轨迹共享6个起点，不视为18个独立项目。相似性、QED、SA和双模型分歧都是诊断线索，不是候选实测活性或合成认证。未跑神经生成器、约束臂、对接、ADMET模型或湿实验。

## 环境与快照

Python 3.11；requirements.txt为原运行环境版本，跨平台安装未验证。中文绘图默认使用Hiragino Sans GB，可自行调整字体。

遵循系列仓库规则，不提交文章HTML、PNG、模型权重和大型输入快照。仅克隆代码不足以完整复跑。先从本地“AI制药第13篇_文章与实验配套.zip”解压，导入所附输入、GNN和完整结果：

```bash
cd aidd_practice/lesson13_generation
python -m pip install -r requirements.txt
python import_snapshot.py /path/to/AI制药第13篇_分子生成
bash run_all.sh
```

experiment会在work缓存重建的RF；第一次按第12篇原索引、排列、配置重训，再与1770条保存预测核对。程序会覆盖当前结果；更改配置应使用独立目录并清除不匹配的RF缓存，保留原结果用于对照。

只重做诊断与图文时，不必重训或重新搜索：

```bash
python scripts/analyze.py
python scripts/attachment_readout.py
python scripts/figures.py
python scripts/article.py
python scripts/verify.py
```

## 脚本

|文件|用途|
|---|---|
|experiment.py|重建RF、建片段库、匹配预算搜索、GNN后评分与历史诊断|
|analyze.py|逐对变化、固定选例、事后属性筛选|
|attachment_readout.py|借鉴附件问题，使用本目录结果补充逐种子变化、共同错误与分歧边界|
|figures.py|8张主图与1张补图|
|article.py|从结果生成文章、嵌入图片预览及仅微信域名链接的发布版|
|verify.py|输入哈希、骨架隔离、预算、动作重构、近邻抽查、选择规则和图文引用检查|

## 预算和结果记录

总共2880个候选评分请求槽位，起点调用另计；重复候选也占逻辑预算，实际不同受评分结构2512个。A从当前结构与8个提议的9个位置随机选择；B选RF最高者，平分保留当前。每轮最多160次提议，缺额明确填自环；8—80重原子边界对两臂相同。跨轮允许重复，缓存单独记账。

结果摘要与审计在results。完整动作、状态、候选与历史诊断CSV由配套快照导入。verification.json是本地完整包已完成的检查记录，不表示克隆本目录后未导入快照就能通过。

attachment_source_audit.json用于说明附件协议的区别，其数字不并入主实验。原始ChEMBL发布号未记录，支持固定输入复跑，不承诺在线重抓得到同一数据。
