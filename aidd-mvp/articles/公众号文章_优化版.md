# AI 制药实操：从 EGFR 数据到候选清单，把第一条 AIDD 流水线跑通、测明白

> 摘要：一万多个分子，11 个阶段，从蛋白结构到主动学习。本文用 EGFR 演示一条能运行、能检查的 AIDD 工程，并把数据清洗、骨架切分和基线训练的完整核心脚本放进正文。比模型分数更重要的，是知道每个结果从哪里来、能说明什么。

学 AI 制药，最容易出现的一种状态是：认识很多模型，却说不清一个分子怎样从数据表走到候选清单。

上一部分我们画了全流程地图。这一篇把地图落到工程：用实验结构定义口袋，用公开 IC50 数据训练模型，用同一份骨架切分比较随机森林和图神经网络，再看分子对接与成药性规则怎样参与判断。

这次还给“跑通”加一个要求：关键产物要能自动检查，模型要确实保存，缩小数据和训练预算以后，整套流程也要能接受冒烟测试。

## 一、先约定目标：我们要交付一份有依据的清单

这个教学项目选择 EGFR。工程使用 UniProt P00533、PDB 1M17 和 ChEMBL 活性数据。1M17 包含配体 AQ4，给口袋位置和重对接提供了参照。

这套工程实际覆盖：教学证据排序、结构处理、数据清洗、活性回归、分子对接、理化性质筛选、主动学习模拟。

它尚未实现新分子生成、逆合成路线、完整 ADMET 预测和真实湿实验回流。主动学习是在已有分子池里选择下一批标签，不等于生成新分子；SAScore 是合成难度的启发式评分，也不等于拿到了可执行合成路线。

把边界讲清楚，后面每一次升级才有明确的位置。

## 四、结构：口袋坐标要从文件里算出来

口袋位置属于具体结构的坐标系。把某篇教程里的三个坐标复制到另一个 PDB，程序即使继续运行，也不能证明对接发生在目标位点。

本项目用共晶配体的坐标计算对接盒子中心，已有产物中的中心为 (22.014, 0.253, 52.794)，盒子边长为 20 Å。03 另用配体周围 5 Å 的蛋白残基解释口袋，得到 20 个残基。

还有一件容易忽略的事：残基编号。03 枚举偏移量，将结构中的氨基酸与 UniProt 序列比较。已有结果是偏移 +24，312/312 个观测残基匹配。因此，结构中的 C773 对应 UniProt C797。

这里使用的是适合当前结构的偏移校验法。遇到插入、缺失或复杂构建体，应升级为正式序列比对与逐残基映射。

## 五、先清洗，再建模：把实验记录变成训练样本

04 先按 UniProt 查询靶点身份，选择人源、单蛋白条目，再按 IC50、nM、精确等号和 binding assay 等条件拉取活性记录。现有原始数据包含 18,381 条记录。

05 要解决两个问题：同一个分子有不同的结构写法；同一个分子可能有多次测量。

标签换算的前提是 IC50 单位已经统一为 nM：

```text
pIC50 = 9 − log10(IC50_nM)
100 nM → pIC50 = 7
数值越大，对应的 IC50 越小
```

代码使用标准化后的、保留手性的 SMILES 聚合，取 pIC50 中位数，同时保留测量次数、标准差和范围。现有清洗结果有 10,468 个分子，3,710 个有多次测量。

高到异常的标签应触发来源核查。本工程把 pIC50 > 11 作为教学性排除阈值；阈值本身不能证明某条实验记录错误。附件原稿将极低浓度直接写成“异常高，需核查”，也把 5×10⁻¹⁸ mol/L 解释为每升不足一个分子，这个换算不成立，本版删除该论断。

下面是实际使用的完整数据清洗脚本。它依赖下一节附出的 _common.py，放在 scripts 目录即可由工程入口调用。

文件：scripts/05_standardize.py

```python
"""05 · 数据清洗：标准化 → 去重 → pIC50 → 聚合

输入：data/raw/raw_activity.csv
输出：data/interim/standardized.csv、data/processed/dataset.csv

要点：
  1) MolStandardize 参数名是 skipStandardization，不是 skipStandardize（写错会全军覆没）
  2) isomericSmiles=True —— 不要顺手把手性洗掉
  3) 同一分子多个测量值时用中位数（抗离群），但必须保留测量次数与标准差
"""
import os
import numpy as np
import pandas as pd

from rdkit import Chem, RDLogger
from rdkit.Chem.MolStandardize import rdMolStandardize

from _common import cfg, ensure_dirs, raw, interim, processed, log, banner, save_json, exists

RDLogger.DisableLog("rdApp.*")
ensure_dirs()
banner("05 · Curation：标准化 → pIC50 → 聚合（比 GNN 更重要的一步）")

src = raw("raw_activity.csv")
if not exists(src):
    raise SystemExit("请先运行 04_fetch_activity.py")
df = pd.read_csv(src)
log(f"读入 {len(df)} 条记录")

# ---------- 1. 保留精确测量值 ----------
a = cfg["activity"]
before = len(df)
df = df[(df["standard_relation"] == a["relation"]) &
        (df["standard_units"] == a["unit"])].copy()
df["standard_value"] = pd.to_numeric(df["standard_value"], errors="coerce")
df = df[df["standard_value"].notna() & (df["standard_value"] > 0)]
log(f"只保留 {a['relation']} / {a['unit']}：{before} -> {len(df)}")

df = df[df["canonical_smiles"].notna()]
log(f"去掉无 SMILES：-> {len(df)}")

# ---------- 2. RDKit 标准化 ----------
params = rdMolStandardize.CleanupParameters()
frag_remover = rdMolStandardize.FragmentRemover()          # 去盐/去小碎片


def standardize(smiles):
    mol = Chem.MolFromSmiles(smiles)
    if mol is None:
        return None
    try:
        mol = rdMolStandardize.Cleanup(mol, params)        # 执行 RDKit Cleanup
        mol = frag_remover.remove(mol)                     # 移除已知碎片；不保证总是只剩一个片段
        if mol is None:
            return None
        return Chem.MolToSmiles(mol, isomericSmiles=True)  # 保留手性
    except Exception:
        return None


df["smiles"] = df["canonical_smiles"].map(standardize)
n_fail = df["smiles"].isna().sum()
df = df[df["smiles"].notna()].copy()
log(f"标准化成功 {len(df)} 条，失败 {n_fail} 条")
if len(df) == 0:
    raise SystemExit("标准化全部失败，请检查 FragmentRemover/参数名")

# ---------- 3. IC50 -> pIC50 ----------
df["pIC50"] = 9 - np.log10(df["standard_value"].astype(float))
print(f"\n  换算示例：IC50 = 100 nM -> pIC50 = 9 - log10(100) = "
      f"{9 - np.log10(100):.1f}")

# ---------- 4. 数据体检：一眼看出有没有脏数据 ----------
print(f"\n  pIC50 分布：min={df['pIC50'].min():.2f}  median={df['pIC50'].median():.2f}  "
      f"max={df['pIC50'].max():.2f}")
weird = df[df["pIC50"] > 11]
print(f"  pIC50 > 11（即 IC50 < 0.01 nM，异常高，需核查）的记录：{len(weird)} 条")
if len(weird):
    top = weird.nlargest(1, "pIC50").iloc[0]
    print(f"    最离谱的一条：pIC50={top['pIC50']:.2f} "
          f"(IC50={10**(9-top['pIC50']):.2e} nM) —— ChEMBL 中待核查的异常记录")
    print(f"    处理方式：MVP 阶段按 pIC50 <= 11 截断（真实项目需回溯 assay 原文）")
n_cut = len(weird)
df = df[df["pIC50"] <= 11].copy()
log(f"截断后 {len(df)} 条")

df[["molecule_chembl_id", "smiles", "pIC50", "assay_chembl_id"]].to_csv(
    interim("standardized.csv"), index=False)
log("wrote data/interim/standardized.csv")

# ---------- 5. 同一分子的多个测量值：中位数聚合 + 保留可信度 ----------
g = df.groupby("smiles")["pIC50"]
agg = pd.DataFrame({
    "pIC50_median": g.median(),
    "n_measurements": g.size(),
    "pIC50_std": g.std(),
    "pIC50_min": g.min(),
    "pIC50_max": g.max(),
}).reset_index()
agg["pIC50_std"] = agg["pIC50_std"].fillna(0.0)
agg = agg.sort_values("pIC50_median", ascending=False).reset_index(drop=True)

multi = (agg["n_measurements"] > 1).sum()
print(f"\n  聚合后唯一分子：{len(agg)}")
print(f"  被重复测量的分子：{multi}（{multi/len(agg):.1%}）")
if multi:
    sub = agg[agg["n_measurements"] > 1]
    print(f"  重复测量的分歧（std 中位数）：{sub['pIC50_std'].median():.2f} 个对数单位")
    print(f"    -> 说明「标签是绝对的」这个假设从数据进来第一天就不成立")

agg.to_csv(processed("dataset.csv"), index=False)
log("wrote data/processed/dataset.csv")

save_json({
    "n_records_in": int(before),
    "n_records_after_filter": int(len(df)),
    "n_standardize_failed": int(n_fail),
    "n_outliers_removed": int(n_cut),
    "n_molecules": int(len(agg)),
    "n_multi_measured": int(multi),
    "median_std_of_multi": float(sub["pIC50_std"].median()) if multi else 0.0,
    "pIC50_range": [float(agg["pIC50_median"].min()), float(agg["pIC50_median"].max())],
}, processed("05_curation.json"))

banner(f"05 done · {len(agg)} 个分子（从 {before} 条记录聚合而来）")
```

## 六、模型之前，先决定怎样考试

ECFP4 将分子局部结构编码为固定长度指纹，本工程采用半径 2、2048 位。随机森林据此预测 pIC50。

训练前更关键的问题是：测试集是否包含训练时见过的化学骨架？06 用 Bemis–Murcko 骨架分组，再用 GroupShuffleSplit 把整组分配到训练或测试集。

这里的 test_size=0.2 作用在骨架分组上，最终测试分子比例不必恰好是 20%。包含手性信息的骨架定义，也不意味着所有相近化学系列都被彻底隔开。若目标是评估新骨架泛化，这仍然比单纯随机拆分更有针对性。

完整的切分与特征脚本如下：

文件：scripts/06_scaffold_split.py

```python
"""06 · 骨架切分 + ECFP 特征矩阵

输入：data/processed/dataset.csv
输出：data/processed/dataset_with_scaffold.csv、X_ecfp.npy、split_indices.json

要点：随机切分下，测试集骨架在训练集里几乎都见过 —— 模型在"默写"。
      骨架切分把重叠清零，指标会明显变差，但那才是真实水平。
"""
import os
import numpy as np
import pandas as pd
from rdkit import Chem, DataStructs, RDLogger
from rdkit.Chem import rdFingerprintGenerator
from rdkit.Chem.Scaffolds import MurckoScaffold
from sklearn.model_selection import GroupShuffleSplit

from _common import cfg, ensure_dirs, processed, log, banner, save_json, exists

RDLogger.DisableLog("rdApp.*")
ensure_dirs()
banner("06 · Split + Featurize：先切分，再谈模型")

src = processed("dataset.csv")
if not exists(src):
    raise SystemExit("请先运行 05_standardize.py")
df = pd.read_csv(src)
log(f"读入 {len(df)} 个分子")

# ---------- 1. Bemis-Murcko 骨架 ----------
def scaffold_of(smiles):
    try:
        return MurckoScaffold.MurckoScaffoldSmiles(smiles=smiles, includeChirality=True)
    except Exception:
        return ""

df["scaffold"] = df["smiles"].map(scaffold_of).fillna("")
log(f"唯一骨架 {df['scaffold'].nunique()} 个（{len(df)} 个分子）")

# ---------- 2. ECFP4 ----------
m = cfg["model"]
gen = rdFingerprintGenerator.GetMorganGenerator(
    radius=int(m["fingerprint_radius"]), fpSize=int(m["fingerprint_size"]))


def featurize(smiles):
    mol = Chem.MolFromSmiles(smiles)
    arr = np.zeros((int(m["fingerprint_size"]),), dtype=np.uint8)
    if mol is None:
        return arr
    DataStructs.ConvertToNumpyArray(gen.GetFingerprint(mol), arr)
    return arr


X = np.stack(df["smiles"].map(featurize).values)
y = df["pIC50_median"].values
np.save(processed("X_ecfp.npy"), X)
log(f"ECFP4 矩阵 X {X.shape}，y 范围 [{y.min():.2f}, {y.max():.2f}]")

# ---------- 3. 两种切分对比 ----------
seed = int(cfg["random_seed"])
test_size = float(m["test_size"])

res = {}
for split_name in ["random", "scaffold"]:
    if split_name == "random":
        rs = np.random.RandomState(seed)
        idx = rs.permutation(len(df))
        n_test = int(len(df) * test_size)
        te, tr = idx[:n_test], idx[n_test:]
    else:
        gss = GroupShuffleSplit(n_splits=1, test_size=test_size, random_state=seed)
        tr, te = next(gss.split(df, groups=df["scaffold"].values))

    tr_s = set(df.iloc[tr]["scaffold"])
    te_s = set(df.iloc[te]["scaffold"])
    overlap = len(tr_s & te_s)
    res[split_name] = {"train": tr.tolist(), "test": te.tolist(),
                       "n_train": int(len(tr)), "n_test": int(len(te)),
                       "n_train_scaffolds": len(tr_s),
                       "n_test_scaffolds": len(te_s),
                       "scaffold_overlap": int(overlap)}
    print(f"\n  [{split_name}] train={len(tr)} test={len(te)}")
    print(f"    训练集骨架 {len(tr_s)}，测试集骨架 {len(te_s)}")
    print(f"    测试集骨架在训练集中出现过的：{overlap} / {len(te_s)}")
    if split_name == "scaffold":
        print(f"    -> 重叠清零，模型面对的是真正没见过的新化学骨架")

save_json(res, processed("split_indices.json"))
log("wrote data/processed/split_indices.json")
```

## 七、先建立一个可靠基线，再比较图模型

完整的 RF 脚本如下。模型保存失败会直接报错，避免出现“预测文件有了、模型却没存下来”的静默故障。

```python
"""07 · Baseline：ECFP4 + Random Forest

输入：data/processed/dataset_with_scaffold.csv、X_ecfp.npy、split_indices.json
输出：models/rf_<split>.joblib、data/processed/07_baseline.json、predictions.csv

要点：不要一上来就 GNN。先有一个无聊的 baseline，
      否则你不知道高级模型到底"额外获得了什么"。
"""
import os
import json
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error, r2_score

from _common import cfg, P, ensure_dirs, processed, path, log, banner, save_json, exists

ensure_dirs()
banner("07 · Baseline：ECFP4 + Random Forest（两种切分对照）")

splits = json.load(open(processed("split_indices.json")))
log(f"数据 {X.shape}，标签范围 [{y.min():.2f}, {y.max():.2f}]")

m = cfg["model"]
out = {}
for name in ["random", "scaffold"]:
    tr = np.array(splits[name]["train"]); te = np.array(splits[name]["test"])
    rf = RandomForestRegressor(n_estimators=int(m["rf_n_estimators"]),
                               random_state=int(cfg["random_seed"]), n_jobs=-1)
    rf.fit(X[tr], y[tr])
    pred = rf.predict(X[te])
    mae = float(mean_absolute_error(y[te], pred))
    rmse = float(np.sqrt(((y[te] - pred) ** 2).mean()))
    r2 = float(r2_score(y[te], pred))
    out[name] = {"n_train": int(len(tr)), "n_test": int(len(te)),
                 "MAE": round(mae, 4), "RMSE": round(rmse, 4), "R2": round(r2, 4),
                 "scaffold_overlap": splits[name]["scaffold_overlap"]}
    print(f"\n  [{name}] MAE={mae:.4f}  RMSE={rmse:.4f}  R2={r2:.4f}")
    import joblib
    joblib.dump(rf, path(P["models"], f"rf_{name}.joblib"))

    # 第一版预测结果（后续 09/10 要用）
    sub = df.iloc[te][["smiles"]].copy()
    sub["true_pIC50"] = y[te]
    sub["pred_pIC50"] = pred
    sub["split"] = name
    sub.to_csv(processed(f"predictions_{name}.csv"), index=False)

delta = out["scaffold"]["MAE"] - out["random"]["MAE"]
print(f"\n  随机切分 vs 骨架切分：MAE {out['random']['MAE']:.3f} -> "
      f"{out['scaffold']['MAE']:.3f}（+{delta/out['random']['MAE']:.1%}）")
print(f"  这不是模型变差了，是此前的好成绩里有「默写」的成分。")

save_json(out, processed("07_baseline.json"))
log("wrote data/processed/07_baseline.json")
banner(f"07 done · scaffold split MAE = {out['scaffold']['MAE']}")
```

|---|---:|---:|

08 使用键消息传递、平均聚合和回归网络。训练标签只按训练集统计量标准化，预测后还原到原始 pIC50 尺度，与 RF 使用同一骨架切分比较。

这一次图模型没有胜过 RF。这个结果支持保留基线，尚不足以证明图模型一般不适合一万条数据。验证集、超参数搜索、多种子重复和数据语义清理，都可能影响结论。本版还把随机种子的设置移到模型初始化之前，修正了初始化未受控的问题；因此重新全量训练的数值可能与历史结果不同。

## 九、成药性：每一道规则回答一个有限的问题

10 计算分子量、logP、TPSA、氢键供受体、可旋转键、QED、SAScore 和 PAINS_A 结构警报。

这些计算可以辅助筛选，但没有给出吸收率、代谢稳定性、hERG 或动物毒性预测。QED 衡量的是一组性质下的类药性；PAINS 命中是需要复核的结构警报；SA 分数也不能替代合成路线、原料和成本评估。

现有结果中的累计漏斗是：

```text
10,468 个分子
  → 5,444：已有实验标签 pIC50 ≥ 7
  → 1,901：同时通过 Lipinski 与 Veber
  → 1,798：再通过 QED，并排除教学阈值定义的可疑高活性
```

这组数字使用的是实验标签，不应写成预测活性。Lipinski 45.7%、Veber 86.7% 则是各自在全体分子上的通过率，不能当作漏斗中的逐层比例。

10 还输出活性、均衡、类药性和低风险四组清单。当前四组统一应用 clean、Lipinski、Veber 条件，与上述 1,798 个分子的累计漏斗条件不同；“低风险”组实际只是未命中所检查 PAINS 且分子量较低，不能解读成低毒性。

Pareto 前沿表达了另一种取舍：在活性和 QED 两项上，没有另一个分子同时更好。已有结果得到 12 个前沿分子。这个前沿是在 clean 子集上计算，不代表每个点都通过全部候选门槛。

## 十、下一批测谁：把主动学习当作可比较的实验

11 保留固定的 scaffold 测试集，只在训练部分划分已标注集和候选池。初始 300 个样本，每批增加 300 个；6 个评估点对应 300、600、900、1200、1500、1800 个已标注分子。

三个策略使用相同初始样本。uncertainty 用三个不同随机种子的 RF 之间的预测标准差；random 随机选；greedy 按预测均值选。这里没有使用 mean + 0.5 × std 的 UCB 公式。

下面是实际不确定性函数，返回候选池预测均值、预测分歧和测试集预测：

文件：scripts/11_closed_loop.py

```python
def rf_uncertainty(train_idx, pool_idx, test_idx, n_models=3):
    """用 n_models 个不同随机种子的 RF 组成 ensemble，std 即不确定性"""
    preds, tests = [], []
    for s in range(n_models):
        m = RandomForestRegressor(n_estimators=int(M["rf_n_estimators"]) // 2,
                                  random_state=SEED + s, n_jobs=1)
        m.fit(X[train_idx], y[train_idx])
        preds.append(m.predict(X[pool_idx]))
        tests.append(m.predict(X[test_idx]))
    Pm = np.stack(preds)
    Tm = np.stack(tests)
    return Pm.mean(0), Pm.std(0), Tm.mean(0)
```

已有全量模拟记录的终点 MAE：uncertainty 为 0.7470，random 为 0.7777，greedy 为 0.8837。uncertainty 在记录的预算点中直到 1,800 样本才首次优于 random。

这提示我们观察整条预算曲线，但不能据此保证主动学习在更大预算下必然反超。greedy 在此处优化的是高预测活性选择，评估指标却是全测试集 MAE；如果目标改成发现高活性分子的数量，需要另算命中率和富集度。

本版修正了末轮评估后仍继续取样的问题，使消耗预算与最后记录的预算一致。真实闭环还需要稳定分子 ID、实验批次、实验条件和新增标签的版本管理。
